# Dawnsbury Days Mods

A collection of mods for [Dawnsbury Days](https://store.steampowered.com/app/2693730/Dawnsbury_Days/).

## Mods

| Mod | Description |
| --- | --- |
| [Dawnsbury.Inventor.Remaster](Dawnsbury.Inventor.Remaster/) | A Dawnsbury Days implementation of the Pathfinder 2e Remastered Inventor class, with optional SpiritDamage compatibility and homebrew settings. |

Each mod is contained in its own top-level folder with its solution, source project, documentation, and any mod-specific assets. Build outputs and local copies of Dawnsbury Days game assemblies are excluded from version control.
